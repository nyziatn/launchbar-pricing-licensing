## 真实评价：它好用的地方和被人抱怨的地方

Macworld 在 2022 年的 Mac Gems 栏目给过它很高的评价，大意是每台新 Mac 上几乎第一个装的就是它。文章里提到，一个输入框就能启动 App、查剪贴板历史，算数和搜网页也在里面，文件移动和重命名同样能用键盘完成。上手几乎零配置，打开，敲几个字母，回车。

抱怨集中在更新节奏。2024 年 Reddit 的 r/LaunchBar 有个帖子直接问这软件还在不在积极开发，有老用户回帖说现在基本只剩每年跟着新系统做一次兼容更新，功能层面很久没大动静了。同一批讨论里也有人提到 Raycast 的文件浏览偏弱、没有 Instant Send，所以他们暂时没走。

两面都成立。你要的是一个磨了很多年、闭着眼也敢按回车的启动器，它没问题；你要的是每周都有新功能、带 AI 的插件生态，它给不了，买之前想清楚自己属于哪种。

还有两个实打实的限制。只支持 macOS，没有 Windows 版。系统要求在往上走，Macworld 当年测的 6.15 还能跑 macOS 10.14.6，第三方记录的最新版 6.24 已经把门槛抬到 Monterey，停在老系统上的 Mac 得先确认能不能装。

至于大版本升级要不要再付一次钱，我没找到能替它打包票的公开条款。商品页的规格栏会写更新政策，这一步别跳过。
